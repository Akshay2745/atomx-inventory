Import devices from a CSV file

  1. Download the sample file and open it in Excel or Google Sheets.
  2. Replace the sample rows with your devices, one device per row. Keep the first row (serial, type, category) as it is.
  3. Save it as CSV. In Excel: File → Save As → "CSV (Comma delimited)". In Google Sheets: File → Download → CSV.
  4. Choose the file below and click Import devices.
